# Presentation formatting: what a user might apply

Status key: **Yes** = works now, **Partial** = works in some places only, **No** = not built yet.

## Text

| Formatting | Where it applies | Status |
|---|---|---|
| Font family | Song, scripture, custom slides | Yes |
| Font size, automatic | Song, scripture, custom slides | Yes |
| Font size, typed in pt | Song, scripture (saved with each item) | Yes |
| Lines per slide (2 to 6) | Song, scripture (saved with each item) | Yes |
| Bold, whole slide | Scripture, custom slides | Yes |
| Italic, whole slide | Scripture, custom slides | Yes |
| Underline, whole slide | Scripture, custom slides | Yes |
| Text colour, whole slide | Scripture, custom slides | Yes |
| Bold, italic, underline on selected words | Any text | No |
| Text colour on selected words | Any text | No |
| Alignment: left, centre, right | Any slide | Partial (centre only) |
| Line spacing | Any slide | No |
| Uppercase or lowercase | Any slide | No |
| Text outline or shadow | Any slide | No |

## Verse numbers and labels

| Formatting | Where it applies | Status |
|---|---|---|
| Verse numbers on or off | Scripture | Yes |
| Verse number colour | Scripture | Yes |
| Verse numbers smaller than the verse | Scripture, projector, .pptx | Yes |
| Verse numbers in the text box and on slides | Scripture | Yes |
| Title and label colour | Scripture, song, projector | Yes |
| Labels on or off (V1, Chorus) | Song, scripture | Yes |
| Title slide on or off | Song | Yes |
| Label size and position | Any slide | No |

## Slide and background

| Formatting | Where it applies | Status |
|---|---|---|
| Background colour, deck-wide | Any presentation | Yes |
| Background colour, per song or scripture | Builder | Yes |
| Background colour, per slide | Builder | No |
| Background image | Any slide | No |
| Aspect ratio 16:9 or 4:3 | Scripture (.pptx only) | Partial |
| Aspect ratio in the projector | Projector | No |
| Margins or padding | Any slide | No |
| Speaker notes | Any slide | No |
| Slide transition | Any slide | No |

## Presentation-wide

| Formatting | Where it applies | Status |
|---|---|---|
| Saved look per song (font, colours, size, lines, labels, repeats) | Lyrics, builder | Yes, once `supabase/lyric-look.sql` is run |
| Saved look per scripture study | Scripture, builder | Yes |
| Remove repeated text | Song | Yes |
| Reorder slides and songs | Builder | Yes (up and down buttons) |
| Drag and drop to reorder | Builder | No |
| Insert a custom slide between items | Builder | Yes |
| Duplicate a slide or study | Scripture, builder | Yes |
| Theme presets (save a look and reuse it) | Any page | No |
| Export to .pptx | Builder, presentations list | Yes |

## Suggested next items (most used first)

1. Bold, italic, underline and colour on selected words.
2. Per-slide background colour in the builder.
3. Alignment (left and right) and line spacing.
4. Theme presets, so one look can be reused across presentations.
5. Drag and drop to reorder.
